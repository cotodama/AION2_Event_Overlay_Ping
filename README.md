# AION2 Event Overlay + Ping

hosigumolaylaさんの [AION2 Event Overlay](https://github.com/hosigumolayla/AION2-Event-Overlay) を基に、TCP Pingとサーバー情報を追加したWindows版です。元のMITライセンスを同梱しています。

## 起動

- **Pythonなし**: `AION2_Event_Overlay_Ping.exe` をダブルクリック。単体で動作します。
- **Python版**: フォルダーを展開したまま `AION2_Event_Overlay_Ping.pyw` をダブルクリック。Python 3.10以上とTkinterが必要です。拡張子は `.phw` ではなく **`.pyw`** です。
- ファイルの関連付けがない場合は `run_overlay.bat` を使います。Python版に追加パッケージは不要です。

## 表示と操作

デイリー更新のすぐ下に選択したサーバーのPingを表示します。その右の **⚙** から、地域と **すべて／天族／魔族** のプルダウンを選ぶと、その下に **1、2、3…の番号順**でサーバー一覧が表示されます。各行の先頭にチェックを入れて複数選択し、最後に **保存** を押すと、選んだサーバー名とPingをオーバーレイに表示します。地域や種族を切り替えてもチェックは保持され、天族・魔族の両方を同時に選べます。「すべて」を選べば同じ一覧で両種族を確認できます。LoginServerは別のチェックで選択します。保存せず設定画面を閉じた場合は選択を変更しません。選んだサーバーはどのタブでも表示・測定を続けます。

- **イベント**: 元ツールのイベント、タイマー、通知。元の上部⚙は従来のイベント設定です。
- **Ping一覧**: 地域を選択し、天族・魔族チェックで絞り込み。最上段に **COMMON / LOGIN（LoginServer）**、その下に天族、魔族の順で縦に表示します。LoginServerは常に一覧に含まれます。IPは通常表示せず、行または上部PingのダブルクリックでIP・TCPポートを編集します。
- **サーバー状態**: All regions / Europe / NA West / NA East / SA / Asia。名前検索・状態フィルターを利用できます。カード表示は縦長向け。**表表示**にチェックすると Status / Server / Faction / Region / Population / Current / Max / Queue / 24H を横に並べ、見出しクリックで並べ替えます。幅が足りなければ横スクロールします。作成制限時は名前の直後にスペースを空けて赤い鍵を描画します。
- **種族バランス**: 同じ地域タブで、地域全体と公開ペアの天族・魔族オンライン人数、割合、人数差を表示します。青のバーは天族、紫のバーは魔族です。欠損・両種族0人はデータなし／人数なしと表示し、比率を作りません。

右下の **◢** をドラッグすると幅と高さを変更できます。Pingの⚙にある「サイズ自動調整」で標準の縦長表示に戻します。**背景・文字・カードをドラッグしてウィンドウを移動**できます。ボタン、入力欄、スクロールバーでは各操作を優先します。右上の最上段には **— 最小化 / □ 最大化・復元 / × 閉じる** を追加し、従来のタイマー・移動・設定アイコンはその下に配置しています。最小化後はWindowsのタスクバーから復元できます。最大化は現在のモニターの作業領域に広げ、もう一度押すと元のサイズと位置に戻ります。

スクロールバーは暗い色の細いバーで、背景をオーバーレイの透過色に統一しています。白い上下矢印をなくし、スクロールが不要なときはバーを表示しません。ホイールとバーのドラッグでスクロールできます。

Pingの⚙には **最前面**、**透過率0〜100%**、**簡易表示（アンテナ＋数値ms）** があります。透過率0%は不透明、100%は背景が透明です。文字と操作ボタンは見える状態を保ちます。透過率と最前面は操作中に反映し、閉じて取り消すと元に戻ります。保存すると次回起動にも引き継ぎます。

Pingの数値は **100ms未満: 緑、100〜200ms未満: オレンジ、200ms以上: 赤**。取得失敗は赤の「応答なし」。サーバー名と通常文字は元の暗いUIに合わせて白です。

## データと取得間隔

[gaming.tools のサーバー状態](https://aion2.gaming.tools/ja/server-status) の公開JSONを**アプリ全体で60秒に1回**、バックグラウンドで取得します。状態とバランスは同じデータを共有し、地域／タブを切り替えても追加のHTTPリクエストは送りません。サーバーの24Hはサイトが返す24時間の人口推移です。ローカルで履歴を蓄積しません。

データ時刻（最も古い地域の更新時刻、UTC）を画面に表示します。取得失敗時は前回データを残し「更新失敗・前回値を表示中」と表示します。初回から失敗した場合は取得失敗を表示します。サイトの形式変更には追従修正が必要です。

Faction Balanceは**オンライン人口**の割合であり、作成キャラクター数全体の比率ではありません。公開ペアは参照サイトが2026-10-02時点で示していた [公式Steamお知らせ](https://store.steampowered.com/news/app/3393110/view/689769594581155928) のペア構成に基づきます。未掲載ペアは勝手に組みません。

TCP Pingは別系統で、表示対象のみを約2.5秒間隔・同時最大12接続・接続タイムアウト1.5秒で測定します。TCP接続時間で、ゲーム内の通信往復時間そのものとは異なります。Ping一覧のIP候補は以前のユーザー用ツールの接続先マップを引き継いでいます。**範囲から増やした候補は公式の確定IP対応表ではなく「＊対応未検証」**です。状態サイトの実在サーバー38台（作成時点）とは別に扱い、人口JSONからIPを推定しません。

設定はアプリ隣の `data/` に保存します。元ツールの既存設定には書き込みません。個人設定・実測値・実行ファイルはGit管理から除外しています。exeを別の場所に置く場合は書き込み可能なフォルダーを使ってください。

## ビルドと検証

`build_exe.bat` でWindows上でビルドします。ビルド時のみPyInstallerが必要です。配布exeはWindows x64 / Python 3.10.5 / PyInstaller 6.22.3で作成しています。

```text
py -3 -m unittest discover -s tests -v
py -3 AION2_Event_Overlay_Ping.pyw --self-check check-source.json
AION2_Event_Overlay_Ping.exe --self-check check-exe.json
```

`--self-check` はインターネットを使わず、一時設定でUI・色分け・タブ・ローカルTCP接続を確認します。通常起動ではこの確認は実行しません。

改良点と元コードの基準コミットは [CHANGES.md](CHANGES.md) に記録しています。画像・フォント・ゲームへの注入を追加せず、サーバーJSONと通常のTCP接続で動作します。


2026-10-04 更新: 「オーバーレイを最前面に表示」は初期状態でオン。オフでは通常のウィンドウ順になり、保存で次回起動にも反映します。イベント・タイマー機能は維持。透明な余白のドラッグ、最小化時のタスクバー表示、通知アイコンのクリックによる復元を追加。設定画面は初回に本体右側へ表示し、ユーザーが移動した座標を記憶します。

白背景になる描画問題への対策: Windows Accent の背景描画を無効化し、元の暗色 #202020 の透過背景を明示的に描画。白背景用テーマは追加せず、元の文字・ボタン色とイベント機能を維持します。

複数画面の背景追従を修正: 負の座標を画面端からの距離として扱っていた背景ウィンドウの座標指定を絶対座標へ変更。左右・上下の正負座標で背景と本体の位置一致を自動確認。物理的な2画面間の実操作は未検証です。
